If you're using an HDMI display with its own built-in speakers, you can configure your system to output audio over the HDMI connection. (These steps should also work for DisplayPort connections.)

## Using the Sound Settings

To make all sound play over HDMI, open the menu in the top right of the screen, then click the <Icon name="fa6-solid:gear" /> icon in the bottom left of the menu.

![Opening the Settings app](img/top-right-menu.png)

Choose the Sound page using the left sidebar.

![Sound settings](img/sound-settings.png)

Under the "Output" section, click the dropdown box to display a list of output devices, then select the HDMI device you wish to use for audio output.

![Output device](img/output-device.png)

After selecting the appropriate device, sound should play through the HDMI connection. You can use the "Test" button to test the HDMI-connected speakers.

## Using PulseAudio Volume Control

The <u>PulseAudio Volume Control</u> utility also allows you to change the sound output. In addition to changing the default output device, you can also set the output device (and volume) on a per-application basis.

<u>PulseAudio Volume Control</u> can be installed using this command:

```bash
sudo apt install pavucontrol
```

Then, open the utility by running `pavucontrol` in a terminal, or by opening the <u>PulseAudio Volume Control</u> app using the Activities menu.

On the "Output Devices" tab, the output device with the green checkmark selected is the default (or "fallback") audio device.

![pavucontrol Output Devices](img/pavucontrol-output-devices.png)

You can set a device as default by clicking the green checkmark next to it.

![Set default output device in pavucontrol](img/pavucontrol-set-default.png)

On the "Playback" tab, each application that's playing audio will be listed. You can change which output device a specific application is using by selecting it under the drop-down box next to that application.

![Set per-app output device in pavucontrol](img/pavucontrol-per-application.png)

## Using a television

### Check the television's HDMI input mode

If a television supports higher refresh rates but only 4K at 30 Hz is available, check the enhanced-input setting for the HDMI port connected to the computer. The name varies by manufacturer; Samsung calls it [Input Signal Plus](https://www.samsung.com/us/support/answer/ANS10003978/). Follow the television's manual, then reconnect HDMI and check the available modes again. Also check the capabilities of the computer's output, cable, and any adapter.

This setting can change the display capabilities the television reports to the computer. It does not guarantee that every advertised mode is supported by the complete connection.

### Forward audio to a soundbar or receiver

If the television forwards the computer's audio to a soundbar or receiver, selecting HDMI output on the computer is only one part of the setup. Check that the television and audio device use their ARC/eARC ports, and follow their manuals for eARC and digital-audio output settings. An encoded audio stream may require a pass-through setting on the television as well as support in the player and receiving device.

Selecting a 5.1 or 7.1 PCM profile does not by itself create Dolby Atmos from stereo audio. The source material, player, connection, and receiving device must support the intended audio format.
